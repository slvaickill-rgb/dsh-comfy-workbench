# ComfyUI 工作台（dsh-comfy-workbench）

> 给 DSH 加一个本地出图面板：选工作流、写一句话、点「生成一张」。**当前版本 1.5.0**（Civitai 模型库 + 自动翻译 + 下载续传）。
> 默认 MOSS-Image 4 步蒸馏档，4 GB 显存能跑，1024² 约 24 秒，中文字渲染是它的强项。

作者：**slvaickill-rgb**

---

## 这是什么

一个 DSH 插件，把本地 ComfyUI 包成侧栏里的工作台。

| 能力 | 说明 |
|---|---|
| **一键出图** | 选工作流 → 写提示词 → 生成，产物落 `output/<源>/<年-月>/`，可存回工作区 |
| **8 份工作流** | MOSS 六档（**标准 底模直出 50 步 / CFG 3**、四步 4 步蒸馏、开关版、FFstyle 12 步、FFstyle 4 步、2.5D 动画）、本机登记（精致写实主义8步）、Anima（按 skill 的 style 档固化：16 步 / cfg 4 / dpmpp_2m / 单段） |
| **LoRA 多选** | 步数旁边的徽标点开就是多选表：列出盘上所有 LoRA，勾几个、各给强度，按勾选顺序写进工作流的 LoraLoader 槽；一个不勾就完全用工作流自带的 |
| **大模型改写** | 两阶段：先判要不要写负面，再按当前工作流的风格改写正向；走宿主 `ctx.llm`，插件不存 key |
| **角色锚定** | 提示词里点名知识库里的角色，自动补「作品 - 罗马音 - 外貌」串（只对 MOSS 工作流） |
| **图库** | 只读扫产物目录、缩略图、NSFW 分级、画风图库（314 画风 / 34,395 样张） |
| **放大 / 预览** | ESRGAN ×2 / ×4；生成过程逐步预览（latent2rgb / taesd） |
| **模型库（Civitai）** | 第四页：按 Civitai 公开 API 搜 LoRA / 底模 / VAE，勾选 → 下到 26 个类别目录之一，SHA256 校验；英文名与简介自动翻中文（可关）；下载有总进度 + 每文件进度条 |

## 三条设计取舍

1. **插件不搬权重，只探盘。** 每次现场读 ComfyUI 的 `extra_model_paths.yaml`、`/object_info`、`models/`，
   所以模型放外置盘、放 NAS 都行；缺文件时工作流标 ⚠ 而不是报错。
2. **CFG=1 不写负面。** 4 步蒸馏档的负面分支根本不参与计算，写进去只是噪音；插件按工作流的实际 cfg 裁决。
3. **改写是「改」不是「创作」。** 只按工作流风格重排措辞，不新增设定；成人内容用全局人设的 §4 尺度兜底。

## 安装

```bash
node tools/install.mjs     # 建联接 + 登记 profile（幂等）
# 重启 DSH —— 新 bundle 不作用于正在跑的进程
```

要求：**DSH** `>=0.2.2-rc.1 <0.2.3-0`、**ComfyUI** `>=0.41.3`（低于它没有 `moss_image` 的 CLIP 类型）、
**Windows**（路径与拉起脚本按 Windows 写的），ComfyUI 跑在 `127.0.0.1:8188`。

出图要四个权重（MOSS 底模 / 文本编码器 / VAE / 4 步 LoRA，共约 12 GB），下载地址、放哪个目录、SHA-256
都写在 **[SETUP.md](SETUP.md)**；换机器、填 `config.json`、故障速查也在那份里。

## 快速验证

```bash
node tools/doctor.mjs             # 装机体检：安装登记 / ComfyUI / 模型 / 缺哪些文件
node tools/selftest-rewrite.mjs   # 39 项：负面判定矩阵、两阶段编排、超时取消
node tools/selftest-anchor.mjs    # 16 项：角色档案解析、命中、注入位置
node tools/selftest-client.mjs    # 21 项：页面静态断言（契约 33、四个标签页、key 不回显）
node tools/selftest-hub.mjs       # 25 项：Civitai 桩测（链接解析、SSRF、307、SHA256、凭据重启恢复）
node tools/selftest-asset.mjs     # 8 项：动图路由
```

全部不联网、不需要 ComfyUI 在线。

## 模型库（Civitai）

第四个标签页。**不内嵌 `civitai.red/models`**——那个页面从本机直连返回 403，宿主 CSP 也有 iframe 前科；
页面自己画，数据走官方 `/api/v1`，地址只作来源标识与外链入口。

- **搜索不要 key**：公开列表无凭据就返回 200；gated 资源才需要 API Key。
- **key 存本机**：`<profile>\.dsh-comfy\hub-credentials.json`，**独立文件、不进 `config.json`**；
  保存时对临时文件 `icacls /inheritance:r` 再 rename。重启 DSH 免填，也可以一键清除。
  勾掉「记住在本机」= 这次只放内存，**不动**已存的那份。
- **下载**：单任务、流式写 `.part`、SHA256 对上才 rename；同名默认 409，单文件上限 2 GiB。
  307 会跳到 `b2.civitai.com`（Civitai 自家域，白名单已放行），**开着代理才下得动**。
  文件名只保留字母数字、`.` `_` `-`、空格与中文；目标目录 realpath 后必须在模型根下。
- **本机代理优先**：出站先探 `127.0.0.1:7897/7890/10809…`（也认 `HTTPS_PROXY`；配置键 `hubProxy` 可指定或关掉）。
  开着 Clash 时一张封面 0.4–0.6 秒、搜索 0.3–0.6 秒；没开才退回境外反代（十来秒）。
- **大图网格 + 详情**：结果是 3:4 大图卡，点开整屏弹层——简介（HTML 剥成纯文本）、标签、底模、版本切换、
  文件勾选与目标目录、下载入口。
- **封面**：页面只认同源 `/dsh-comfy/hub/cover?u=`，宿主取图再吐回去（渲染进程不保证放行 `image.civitai.com`）。
  本机直连 `image.civitai.com` 两条路都不通（投毒 DNS + hosts 劫持到 `127.0.0.1`），失败后自动退回
  `images.weserv.nl` 反代；10 分钟进程内缓存 + in-flight 合并挡重复请求。**首次一张要十来秒**，之后走缓存。
- **已下载**：搜索结果按本地扫盘名单打「已下载」角标（按文件名匹配，不依赖下载历史）；勾上「只看已下载」会切成
  **本机图库**——本地文件按大图卡片排开，封面 / 模型名 / 触发词靠 `hubLocalFiles` 按文件名去 Civitai 补，
  结果缓存在 `<profile>/.dsh-comfy/local-catalog.json`（7 天）；每次最多现查 8 个，页面自动循环到查完，
  查不到的用占位封面 + 文件名（改过名或非 Civitai 来源的认不出来）。点卡片能打开该模型的详情。
- **触发词**：下载时把 Civitai 的 `trainedWords` 记到 `<profile>/.dsh-comfy/lora-triggers.json`；LoRA 下拉里每条带一个
  「词 ⧉」小胶囊，点一下复制（多个词按逗号拼好）。没有记录的老 LoRA 显示「查触发词」，按文件名去 Civitai 回填
  （面板头有「补触发词」一次查 8 个）。大模型改写两阶段都会把「当前 LoRA + 触发词」写进提示词，并要求
  「不要写 `<lora:...>` 标记、触发词原样保留在靠前位置」。
- **自动翻译**：结果里的英文名与详情简介走宿主 `hubTranslate` 批量翻成中文（同一句只翻一次，进程内缓存），
  中文名压在上面、英文留一行小字；详情里可切「看原文 / 看译文」。翻译走 `ctx.llm`，没配模型时自动停在英文，不报错。
  （模型助手对话框已下线，`hubChat` / `hubAdvice` 接口留着但页面不再调。）
- **下载进度**：总进度条 + 每个文件的进度条与百分比；底栏常驻一条细条，滚动到哪儿都看得见当前任务。

## 适合 / 不适合

**适合**：本地单机出图、4 GB 显存、要中文字渲染（招牌 / 菜单 / 海报）、要明确手控每个参数。

**不适合**：要云端并发、要跨平台（macOS / Linux 未测）、要「一句话生成整套资产」。
